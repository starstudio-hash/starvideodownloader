Quick setup steps

Download the Windows installer

Start on the PC download page and download Star.Video.Downloader.Setup.exe. This is the normal Windows installer for the app.

Install the desktop app

Run the setup wizard, choose the install location if needed, then open Star Video Downloader from the Start Menu or desktop shortcut.

Install yt-dlp and ffmpeg

Use the app's Tools section to install or update the helper tools. yt-dlp handles site support, and ffmpeg handles merging, conversion, and repair.

Paste the YouTube URL

Paste the video link, choose MP4 or another format, pick a quality, and start the download. Free users can save up to 1080p.
