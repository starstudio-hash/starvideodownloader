How to convert videos on Windows PC

Install the PC app

Download the setup installer from the PC video downloader page and open Star Video Downloader.

Install ffmpeg

Open the Tools section and install or update ffmpeg. This is the conversion engine used locally by the app.

Choose a file

Select a video you downloaded or any local file you want to convert. Choose the output folder before starting longer jobs.

Pick the output format

Choose MP4 for compatibility, MKV for flexible archiving, WebM for web workflows, or audio-only formats when you need sound.

Format Use it for Why
